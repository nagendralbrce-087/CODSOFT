# Face Detection and Recognition

## Description

This project detects human faces in images using OpenCV Haar Cascade Classifier.

The system identifies faces and draws bounding boxes around detected faces.

## Features

- Face Detection
- OpenCV Haar Cascade
- Image Processing
- Face Localization

## Technologies Used

- Python
- OpenCV
- Matplotlib

## How It Works

1. Upload an image.
2. Convert image to grayscale.
3. Detect faces using Haar Cascade.
4. Draw bounding boxes.
5. Display result.
