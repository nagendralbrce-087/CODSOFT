# Rule-Based Chatbot

## Description
A simple chatbot built using Python that responds to user inputs based on predefined rules using if-else statements.

## Features
- Greets users
- Answers basic questions
- Ends conversation when user types "exit"

## Technologies Used
- Python

## Sample Interaction

You: hello
Bot: Hello! How can I help you?

You: bye
Bot: Goodbye! Have a nice day.
