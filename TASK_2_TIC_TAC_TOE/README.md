# Tic-Tac-Toe AI

## Description

This project implements an AI-powered Tic-Tac-Toe game using the Minimax algorithm.

The player competes against an AI that always chooses the optimal move.

## Features

- Human vs AI
- Minimax Algorithm
- Unbeatable AI
- Command-line gameplay

## Technologies Used

- Python

## How to Run

Run the notebook and enter positions from 1 to 9.
