# Recommendation System

## Description

This project implements a simple Movie Recommendation System using Content-Based Filtering. The system recommends movies based on genre similarity. It uses machine learning techniques such as Count Vectorization and Cosine Similarity to find movies that are similar to a user's selected movie.

## Features

- Movie recommendation based on genre similarity
- Content-Based Filtering approach
- Uses Cosine Similarity for recommendations
- Simple and easy-to-understand implementation
- User-friendly recommendation output

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn

## How It Works

1. Load the movie dataset.
2. Convert movie genres into numerical vectors using CountVectorizer.
3. Calculate similarity scores using Cosine Similarity.
4. Recommend movies with the highest similarity scores.
